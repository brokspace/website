Shard Hub (prévia)

A casa oficial de shards, skills e agentes para o Brokspace.

Em breve

O Hub está sendo construído. Até ele abrir, instale shards de qualquer repositório git com brok shard install <url>.

O Brokspace Hub será o catálogo oficial de shards feitos pelo time do Brokspace e, mais tarde, um registro em que qualquer pessoa poderá publicar, no espírito do Docker Hub:

  • Shards e pacotes de skills oficiais, revisados e versionados.
  • Instalação com um comando pela CLI e pela Brokspace IDE.
  • Permissões às claras: cada shard lista o que pode ler, escrever, executar e acessar antes de você instalá-lo.

Hoje, crie os seus com Shards e Skills, começando pelo template de shard.
