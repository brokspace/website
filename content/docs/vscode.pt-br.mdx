A extensão Brokspace leva seu workspace local do Brokspace para o VS Code.
Ela foi feita para o VS Code e projetada para rodar em editores baseados nele
(veja [Outros editores](#outros-editores)). A extensão
usa a CLI `brok`, então seu terminal, agentes de código e editor compartilham
a mesma pasta `.brokspace/`, índice, configurações de LLM e memórias.

## Instalação

Instale a extensão pelo [Marketplace do VS Code](https://marketplace.visualstudio.com/items?itemName=brokspace.brokspace) ou execute:

```sh
code --install-extension brokspace.brokspace
```

A extensão precisa da ferramenta de linha de comando `brok` (0.4.0 ou mais
recente). Se você já a tem, por [Homebrew, APT ou o binário da release](/pt-br/docs/getting-started),
a extensão a encontra no `PATH` ou em `brokspace.brokPath` e a usa.

### Download no primeiro uso

Se o `brok` não estiver instalado, a extensão pergunta antes de fazer qualquer
coisa. Se você aceitar, ela:

- baixa o executável `brok` da sua plataforma das
  [releases do brokspace/brok no GitHub](https://github.com/brokspace/brok/releases)
  (cerca de 150 a 220 MB, nenhum outro host);
- confere o arquivo com o SHA-256 publicado ao lado dele e não instala nada se
  não bater;
- guarda tudo na pasta de armazenamento da própria extensão: sem permissão de
  administrador e sem alterar o seu `PATH`.

Um `brok` que você já tenha sempre tem prioridade sobre a cópia baixada. Execute
**Brokspace: Download and Install brok** para fazer isso depois; desinstalar a
extensão remove a cópia. O download é uma conveniência: se você gerencia
ferramentas com um gerenciador de pacotes, instale o `brok` assim e a extensão
o usará (e não atualizará a cópia baixada). O download precisa de acesso à rede
para github.com uma vez.

### Outros editores

O Visual Studio Code é o editor suportado e testado. A extensão usa apenas a
API pública de extensões do VS Code e declara o VS Code 1.90 como mínimo,
então foi projetada para instalar em editores que implementam essa API, como
Cursor, Windsurf, Devin Desktop e VSCodium. É um objetivo de projeto, não uma
garantia:

- **Não testada neles.** Testamos apenas no VS Code. Um fork pode estar atrás
  da API do VS Code ou não ter partes dela (o participante de chat
  `@brokspace` e o registro do MCP dependem de APIs mais novas e são ignorados
  onde faltam). Recursos que precisam de uma API ausente ficam desativados, e o
  resto continua funcionando.
- **Onde obter.** O Visual Studio Marketplace é para os produtos da própria
  Microsoft, então esses editores não instalam por ele. Baixe
  `brokspace-<versão>.vsix` nas
  [releases do GitHub](https://github.com/brokspace/vscode/releases) e use
  **Extensions: Install from VSIX**. A publicação no Open VSX, o registro que
  muitos deles usam, está planejada, mas ainda não existe.
- **Reporte problemas.** Se algo não funcionar no seu editor,
  [abra uma issue](https://github.com/brokspace/vscode/issues) com o editor e a
  versão. Corrigimos o que for razoável.

A CLI `brok`, e com ela o MCP e as skills dos seus agentes de código, não
depende de nenhum editor.

Abra uma pasta de projeto e execute **Brokspace: Set Up
Workspace** na barra lateral do Brokspace ou na Paleta de Comandos. Isso cria
`.brokspace/brok.yml`, indexa a pasta e inicia o Brokspace.

## O que você pode fazer

- Buscar no workspace e nos workspaces vinculados pelo significado ou nome.
- Fazer perguntas com links para as fontes ou conversar sem sair do editor.
- Revisar suas alterações ou as alterações preparadas e escrever uma mensagem
  de commit.
- Salvar, navegar e buscar memórias, incluindo o código selecionado.
- Gerenciar workspaces vinculados, skills e shards.
- Registrar o servidor MCP do Brokspace para o Copilot e outros clientes
  compatíveis.

A extensão precisa de um LLM e do shard `brok-agent` para respostas, revisões
e mensagens de commit. A busca funciona sem um LLM.

## Comandos úteis

| Comando | O que faz |
|---|---|
| **Brokspace: Search** | Busca código com `Ctrl+Alt+F` (`Cmd+Option+F` no macOS). |
| **Brokspace: Open Chat** | Faz uma pergunta com `Ctrl+Shift+Alt+B` (`Cmd+Shift+Option+B` no macOS). |
| **Brokspace: Set Up Workspace** | Cria e indexa o workspace Brokspace. |
| **Brokspace: Doctor** | Verifica o executável, workspace e serviços. |
| **Brokspace: Report a Bug** | Abre uma issue com diagnósticos, com segredos ocultos. |

Para detalhes de configuração e desenvolvimento, consulte o
[repositório da extensão](https://github.com/brokspace/vscode).
