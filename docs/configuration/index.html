Configuration reference

brok init writes .brokspace/brok.yml with comments (commands that change the file, like brok setup llm, keep them; comments you add yourself are dropped when brok rewrites the file). Every key is optional; missing keys take the defaults below. Unknown keys are rejected with a "did you mean" style error, so typos never go unnoticed.

Changes take effect on the next command (or after restarting brok run). Changing embeddings.model, embeddings.dimensions or index.store triggers a rebuild of the affected partitions on the next brok index.

workspace

KeyDefaultDescription
submodulestrueIndex git submodules and git repositories nested in the workspace (up to 4 levels, e.g. a folder of repos) as independent hot partitions.

index

KeyDefaultDescription
include["**/*"]Globs (relative to the workspace root) of files to index.
exclude.git, .brokspace, target, node_modules, dist, build, lock files (*.lock, pnpm-lock.yaml, package-lock.json, npm-shrinkwrap.json, go.sum), *.min.jsGlobs to skip. .gitignore files are always honored on top of this.
max_file_kb512Larger files are skipped. Binary files (NUL bytes) and non UTF-8 files are always skipped.
max_chunk_lines120A syntactic unit longer than this is split: containers into members, other nodes at line boundaries.
storeautoauto (LanceDB when compiled in), lancedb or arrow (memory-mapped Arrow IPC, exact vector search).

embeddings

KeyDefaultDescription
enabledtruefalse runs on BM25 text search only: no download, minimal memory.
modelnomic-embed-text-v1.5The only supported model today.
variantquantizedquantized (~140 MB, int8) or full (~550 MB, fp32).
dimensions768Matryoshka truncation: 64, 128, 256, 512 or 768.
deviceautoauto, cpu, cuda, coreml, directml (GPU devices need the matching build feature).
batch_size16Texts per inference batch.

Model files are downloaded once per user and shared by every workspace: ~/.cache/brokspace/models (Linux), ~/Library/Caches/brokspace/models (macOS), %LOCALAPPDATA%\brokspace\models (Windows). Set BROK_MODELS_DIR to use another directory. A copy inside .brokspace/cache/models/ (from older versions) keeps working.

User defaults

brok setup llm also stores your LLM choice in the user configuration (~/.config/brokspace/config.yml, ~/Library/Application Support/brokspace/ or %APPDATA%\brokspace\; override with BROK_CONFIG_DIR). brok init applies it to every new workspace, so you choose a model once per machine.

search

KeyDefaultDescription
limit8Default number of results.
cold_weight0.85Score multiplier for partitions other than the one you run the command from.

llm

OpenAI-compatible chat completion endpoints used by brok-agent.

KeyDescription
defaultProvider used unless brok ask --provider says otherwise. Must exist in providers.
providers.<name>.base_urlURL up to and including /v1.
providers.<name>.modelModel name as the provider expects it.
providers.<name>.api_key_envName of the environment variable holding the key. Keys never go in this file.
providers.<name>.temperature / max_tokensOptional sampling settings.

sync

Where the index is mirrored, configured with brok setup sync.

KeyDescription
backendnone, s3, r2, minio or git-lfs.
remote.bucket / prefix / region / endpointObject storage coordinates.
remote.access_key_env / secret_key_envNames of the variables holding the credentials (default AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY).

git-lfs tracks .brokspace/databases/** with Git LFS and stops ignoring it, so the index travels with the repository. The object storage sync engine (brok sync) is on the roadmap: today brok setup sync records the target.

shards

Each shard documents its own settings. For brok-agent see its README.
