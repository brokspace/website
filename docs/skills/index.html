Skills

A skill is a small, reusable workflow written for AI agents: a folder with a SKILL.md (YAML frontmatter name + description, then instructions) and optional reference files. Brokspace uses the same Agent Skills format as Claude Code, Codex, Cursor and GitHub Copilot, so a skill written once works everywhere.

Two kinds

User-invokedModel-invoked
Who starts itOnly you, by typing /nameYou, or the agent when the task fits
Frontmatterdisable-model-invocation: true(default)
RoleOrchestrates a flow (/to-spec, /triage)A reusable discipline (tdd, code-review)
DescriptionOne human-facing lineRich "Use when..." triggers

Built-in skills

brok ships a curated set, embedded in the binary (source: skills/). They cover the whole development loop that Brokspace itself uses: align, specify, slice, build test-first, review, ship.

Not sure where to start? Type /ask-brok in your coding agent and describe your situation.

Using skills

In your coding agent (the main way):

Skills land in .claude/skills/ and the portable .agents/skills/ (read by Codex, Cursor, Copilot and others). Folders are marked .brokspace-managed and refreshed on every export; brok never overwrites a folder it did not create. Commit them to share with your team.

On your local LLM, through brok-agent (needs brok run):

The skill's instructions (and the reference files it links) become the system prompt; Brokspace adds relevant code from the index as context.

Writing your own

Workspace skills in .brokspace/skills/<name>/ override built-ins with the same name, so you can tailor any built-in to your team. Keep skills short and explicit: small local models follow them too. The built-in write-skill skill walks your agent through it.

Sharing skills: skill shards

A skill shard is a shard with no process, just skills. Publish it as a git repository and anyone can install it:

shard.json of a skill shard:

A shard can also ship skills next to its process (entrypoint + skills).

Precedence

When names collide, the first wins: workspace (.brokspace/skills/) > installed shards > built-in. brok skill list reports shadowed skills.
